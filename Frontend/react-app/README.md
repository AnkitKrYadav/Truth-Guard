Project Overview – What it does: “Truth-Guard is a news verification dashboard that shows trending news, stats, and allows fact-checking.”

Folder Structure – Mention backend, frontend, database folders.

Installation Instructions:

# Backend
cd Backend
pip install -r requirements.txt
python app.py

# Frontend
cd Frontend/react-app
npm install
npm start


Notes on Data – Trending news comes from news.db. Some stats are placeholders.

Future Improvements – Dashboard stats real-time, backend modules fully functional (fact_check.py, etc.), better category styling.
